# 🎯 Pruebas María 2.0

Sistema de reporte ejecutivo offline-first para análisis y seguimiento de pruebas.

---

## 🚀 Inicio Rápido

```bash
# Instala dependencias (si no lo has hecho)
pnpm install

# Inicia servidor de desarrollo
pnpm dev

# Abre http://localhost:3000 en tu navegador
```
