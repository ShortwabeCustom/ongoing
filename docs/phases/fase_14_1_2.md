## 🏗️ Arquitectura Implementada

### URL State Management

**Flujo de Filtros**:
```
URL actual (/findings?q=...&dateType=session&dateTo=...)
  ↓
[Page Load / useUrlSync]
  ↓
Initial state hydrated from URL
  ↓
SearchFindings component renders con estado inicial
  ↓
Usuario modifica filtros en AdvancedFilterPanel (draft state)
  ↓
Usuario hace click "Aplicar"
  ↓
onApply() en SearchFindings
  ↓
setAdvancedFilters(newFilters)
  ↓
syncToUrl(filters) → router.replace()
  ↓
URL actualizada con nuevos parámetros
  ↓
Búsqueda ejecutada con resultados
```

**Fuentes de Verdad**:
```
URL SearchParams
  ↓ (hydration en mount)
React State (advancedFilters, searchTerm, statusFilter, priorityFilter)
  ↓ (en memoria, usuario edita draft)
AdvancedFilterPanel Draft State
  ↓ (click Aplicar)
URL SearchParams nuevamente
  ↓ (replace, no push → evita crear historial innecesario)
```

### Timezone Handling

**Decisión: UTC Explícito (Opción C)**

```typescript
// Antes (implícito, browser timezone)
const now = new Date()  // Browser timezone
const start = startOfDay(now)
return start.toISOString()  // Conversión implícita a UTC

// Después (UTC explícito)
const nowUtc = new Date()  // Siempre UTC en servidor/API
const startIso = `${nowUtc.toISOString().split('T')[0]}T00:00:00.000Z`
return startIso  // Siempre UTC
```

**Rationale**:
- Server runs in UTC
- PostgreSQL expects UTC
- Consistent across all timezones
- No ambiguity at midnight boundaries
- Documented product timezone: UTC

**Future enhancement**: Si usuarios en México requieren "Hoy" = "su día local", implementar timezone selector + backend conversion (separate FASE).

### Saved Filters

**Comportamiento**:
```
SavedFilterEntry {
  id: string
  name: string
  q?: string
  status?: string[]
  priority?: string[]
  filters: AdvancedFilterValues  // ← Aquí se persisten todos los date filters
  createdAt: number
  updatedAt: number
}
```

**Persistencia**: ✅ dateType, dateFrom, dateTo se guardan automáticamente
**Recuperación**: ✅ Al restaurar filtro guardado, restaura también date filters
**Backward Compat**: ✅ Filtros legacy (sin dateType) defaults a 'created'
