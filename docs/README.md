## 📱 Comandos Esenciales

```bash
# Desarrollo
pnpm dev              # Servidor local con hot-reload

# Build
pnpm build            # Compilar producción
pnpm start            # Ejecutar producción

# Calidad
pnpm lint             # Validar código

# Git
git log --oneline     # Ver commits
git status            # Ver cambios
```
